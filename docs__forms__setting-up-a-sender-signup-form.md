Setting up a Sender Signup Form

Requires Pro Standard or higher

Click Add Element

Click Form to create a new Form element.

Set Type to Signup, then Via Sender.

Enter your Sender API Token, which can be found (or if necessary created) by following these instructions.

(Optional) Enter one or more subscriber Group IDs, which can be found by following these instructions.

(Optional) Check Trigger automations to automatically activate automations when creating new subscribers.

(Optional) Click the Fields tab and rename or toggle the form's fields.

(Optional) Click the Button tab and change the form's submit button Label.

(Optional) Check Collect UTM parameters to automatically include all detected UTM parameters as custom fields. The following fields will be populated if detected: {$utm_source}, {$utm_medium}, {$utm_campaign}, {$utm_term}, and {$utm_content}.

(Optional) Add custom fields for {$site_url}, {$site_title} and {$site_form} to automatically record the site URL, title and unique form ID with each signup.

You're done! The site should now have a fully functional Sender signup form.
