Adding a Header

When using Sections, you can use a Header Marker to create a header, a special region at the top of the site that remains visible on every section. Here's how:

Click Add Element

Click Control to create a new Control element.

Set Type to Header Marker.

Drag the header marker to where you'd like the header to end, then release click to drop it. This assigns all elements before the header marker (up to the top of the site) to the site's header.

Note: The header must be physically located before all other elements on the site.

You're done! The elements assigned to the header should now be visible at the top of every section. Note that you can also add a footer using a similar process.
