Serving Fonts Locally

Requires Pro Standard or higher

In addition to providing the usual selection of web safe fonts, Carrd also offers a number of custom fonts served via the high performance Google Fonts API. However, if you're in a situation where you'd prefer to serve these fonts directly from a given site instead of an external API, here's how to do it:

Click Publish

Click the Settings tab.

Under Options, check Serve fonts locally.

Click Publish Changes

You're done! Any font assets previously served via the Google Fonts API will now be served directly from the site itself.
