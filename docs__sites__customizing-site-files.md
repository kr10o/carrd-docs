Customizing Site Files

Requires Pro Plus or higher

More advanced use cases may require you to customize one or more of a site's supporting files (such as its robots.txt or ads.txt files), in which case the Site Files feature will allow you to do just that. Here's how:

Open the Dashboard.

Click the Sites tab.

Locate the site in question, then click its Manage icon.

In the sidebar, click Files.

Locate the file you wish to edit, then click its Edit icon:

ads.txt
Lists all sellers authorized to sell digital advertising inventory on the site (learn more).
age.xml
Provides age classification data for the site (learn more).
analytics.txt
Verifies ownership of the site for the purpose of regaining access to a Google Analytics property (learn more).
app-ads.txt
Lists all sellers authorized to sell digital advertising inventory within an app associated with the site (learn more).
apple-app-site-association
Securely associates the site with a native app within Apple's App Store (learn more).
apple-developer-merchantid-domain-association
Verifies the site's domain for use with Apple Pay (learn more).
assetlinks.json
Securely associates the site with a native Android app (learn more).
atproto-did
Associates the site with an AT Protocol decentralized identifier (DID), allowing its URL to be used as an identifier within supported federated networks (learn more).
com.apple.remotemanagement
Configures the site for account-driven user enrollment with Apple devices (learn more).
discord
Connects the site to a Discord profile when using the Verify with HTTPS verification method.
funding.json
Lists individuals and organizations that accept financial support related to the site or its associated projects (learn more).
humans.txt
Provides human-readable information about the site's creators and contributors (learn more).
llms.txt
Provides structured markdown-formatted information about the site for use by large language models and AI agents. (learn more).
manifest.json
Describes the behavior of the site when installed as a progressive web app (learn more).
microsoft-identity-association.json
Securely associates the site with an Azure app (learn more).
nostr.json
Verifies a Nostr account using NIP-05 (learn more).
robots.txt
Determines how search engines should access and index content on the site (learn more).
sellers.json
Lists all entities authorized to sell or resell digital advertising inventory on the site (learn more).
service-worker.js
Provides the site with additional capabilities when installed as a progressive web app (learn more).
vcard.vcf
Provides contact information as a downloadable VCF (virtual contact file) also known as a "vCard" (learn more).

Make your changes to the file's contents (or simply clear its contents to omit this file).

Click Update File

You're done! You can now preview the file's contents by clicking its Preview icon.

The file can also be linked to directly within the site using a file URL (for example, file:vcard.vcf).
