Basics

New to building with Carrd? Here's a quick rundown of some of the more common builder tasks:

Adding an Element

Click Add Element

Click on the type of element you'd like to add (for example, Text to add a new Text element). This will add a new element of the selected type to the end of the site and open its properties panel.

Using the panel, customize the new element as needed.

(Optional) Click Done to close the panel.

You're done! The new element should now be added to the site.

Moving an Element

Click and begin dragging the element you'd like to move.

Drag the element before or after another element (a green bar will appear indicating which side of the element you're currently targeting).

Release click to drop the element.

You're done! The element should now be moved.

Editing an Element

Click the element you'd like to edit to open its properties panel.

Using the panel, edit the element as needed.

(Optional) Click Done to close the panel.

You're done! The element should now be edited.

Deleting an Element

Click the element you'd like to delete to open its properties panel.

At the bottom of the panel, click Delete

You're done! The element should now be deleted.

Cloning an Element

Click the element you'd like to clone to open its properties panel.

At the bottom of the panel, click Clone

You're done! A clone of the element should appear immediately before it.
