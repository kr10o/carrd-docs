SITES
Building a Custom Template

Requires Pro Lite or higher

Build or open the site you'd like to use as a template in the builder.

Click Publish

Under URL, select Save as a template.

Click Save

You're done! When selecting a starting point for a new site, your custom template will now be available as an option under the Custom category.
