Redeeming a Code

A redeem code is a unique, 15-digit code linked to a specific item. If you've discovered or received such a code, you can redeem the item linked to it by following the steps below:

Open the Dashboard.

Click your Account avatar in the corner.

In the sidebar, click Library.

Click Redeem

Enter your code. Note that your code must be in XXXXX-XXXXX-XXXXX format.

Click Redeem Code

You're done! The item linked to the code should now be available in your library.
