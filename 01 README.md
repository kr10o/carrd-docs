# Carrd documentation archive

Collected: 2026-10-27
Source: https://carrd.com/docs

## Scope

Recursively followed links on /docs pages. Saved other same-origin pages linked from documentation without recursively expanding the entire non-documentation website. External origins were skipped. URL fragments were deduplicated. Pages were opened and scraped sequentially through the browser.

Files preserve rendered page text and a list of page hyperlinks, not original HTML, visual layout, or embedded images. Linked image and archive URLs have reference files; the binary assets were not downloaded. Template demos contain only their available rendered text.

## Link lists

- all-links.txt: full same-origin crawl list
- manifest.json: source URLs, redirects, file names, extraction status
