Generating a QR Code

Requires Pro Lite or higher

You can instantly generate a downloadable QR code for any published site (or custom template demo) by following these steps:

Open the Dashboard.

Click the Sites tab.

Locate the site for which you'd like to generate a QR code, then click its Manage icon.

Click the QR code icon inside the box containing the site's URL.

Once generated, hover the QR code and click Download PNG to download it as a high-resolution PNG image.

You're done! Scanning the downloaded QR code with a mobile device should automatically open the published site (or custom template demo) in a browser.
