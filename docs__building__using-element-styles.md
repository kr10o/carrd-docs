Using Element Styles

Ordinarily, each element has to be customized individually and entirely independent of other elements. While this generally works out pretty well, there are times when this can become quite tedious (for example, making the same minor change to a dozen identical elements). Element Styles addresses this by allowing multiple elements to be linked to a single set of settings (a style) which, when changed, will also change the appearance (and if applicable, animations) of all elements linked to that particular style.

Creating a Style

Click the element you'd like to use as a basis for a style.

Click Appearance

Click the style dropdown in the upper-right corner of the properties panel.

Click Add Style. This will create a new style based on the appearance (and if applicable, animations) of this element, then automatically link the element to it.

(Optional) Click the new style's Edit icon to rename it.

You're done! A new style has been created that can now be linked to by other elements of this type.

Linking an Element to a Style

Click the element you'd like to link to a style.

Click Appearance

Click the style dropdown in the upper-right corner of the properties panel.

Select the style you'd like to use.

You're done! This element will now be linked to the selected style. Making changes to the appearance or animation settings of this or any other element linked to this style will apply those changes to all elements linked to this style.

Renaming a Style

Click an element of the style's type.

Click Appearance

Click the style dropdown in the upper-right corner of the properties panel.

Click the style's Edit icon and enter a new name.

You're done!

Deleting a Style

Click an element of the style's type.

Click Appearance

Click the style dropdown in the upper-right corner of the properties panel.

Click the style's Delete icon.

You're done! The style is now deleted. All elements that were previously linked to it will retain their current appearance and animation settings, but they can now be changed independently (or linked to a different style).
