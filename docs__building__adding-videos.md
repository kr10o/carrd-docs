Adding Videos

The Video element allows you to directly upload videos or embed them from YouTube, Vimeo, or Twitch. Here's how:

Embedding a Video

Click Add Element

Click Video to create a new Video element.

Set Type to Embed.

Paste in the URL of the video you'd like to embed. Currently supports URLs in the following formats:

Bilibili
https://www.bilibili.com/video/xxxx
Bunny Stream
https://iframe.mediadelivery.net/embed/xxxx/yyyy
Cloudflare Stream
https://customer-xxxx.cloudflarestream.com/yyyy/manifest/video.m3u8
Facebook
https://www.facebook.com/username/videos/xxxx
https://www.facebook.com/watch/?v=xxxx
Google Drive

https://drive.google.com/file/d/xxxx/view

Requires video to be accessible to "Anyone with the link" (learn more).
Loom
https://www.loom.com/share/xxxx
TikTok
https://www.tiktok.com/@username/video/xxxx
Twitch
https://www.twitch.tv/username
https://www.twitch.tv/videos/xxxx
https://www.twitch.tv/username/clip/xxxx
Vidyard
https://share.vidyard.com/watch/xxxx
https://video.vidyard.com/watch/xxxx
Vimeo
https://vimeo.com/xxxx
YouTube
https://www.youtube.com/watch?v=xxxx
https://youtube.com/shorts/xxxx

(Optional) Toggle video options (if applicable).

You're done!

Uploading a Video

Requires Pro Lite or higher

Click Add Element

Click Video to create a new Video element.

Set Type to Upload.

Select an MP4 video to upload. The video must be encoded in H.264 format.

(Optional) Toggle video options (like Loop playback or Show player controls).

You're done!
