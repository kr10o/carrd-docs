Adding a PayPal Button

The PayPal widget allows you to add buttons to accept payments, donations, and subscriptions via PayPal. Here's how to use it:

If you haven't done so already, create a PayPal account.

Back at Carrd, Click Add Element

Click Widget to create a new Widget element.

Set Type to PayPal.

Choose the Action you'd like this button to perform:

Buy
Pays for a single item.
Cart
Adds a single item to the user's PayPal cart.
Donate
Donates a fixed amount.
Subscribe
Subscribes to a subscription or service.

Enter a Name, Amount, and other payment details.

(Optional) Enter a Return URL, which can be any valid URL or blank to use the site's current URL.

Enter your PayPal Merchant ID, which can be found using these instructions.

You're done!
