Setting a Background Slideshow

Requires Pro Lite or higher

Select the site's Background element.

Set Style to Slideshow.

Click the first slide (labeled "Untitled") to expand it.

Click Upload

Select an image to use as the slide's background.

Resize and crop as needed, then click Accept

Set Position to the corner or side of the image that should be prioritized on mobile screens.

(Optional) Choose a Motion option.

Click Add to add additional images, repeating steps 3 through 8 for each.

(Optional) Click Done to close the properties panel.

You're done!
