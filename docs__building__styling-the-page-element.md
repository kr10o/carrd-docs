Styling the Page Element

Select the site's Page element.

Set Style to one of the following:

Default
A simple, transparent area that can be positioned in the center, corner, or edge of the screen. Useful if you're building either a simple layout or a more advanced layout using mostly container elements.
Box
Encloses the site's elements in a solid, styleable box that can be positioned in the center, corner, or edge of the screen. Supports Background Friendly mode on mobile screens.
Wide Box
Encloses the site's elements in a solid, styleable box that spans the width of the page. Can be positioned at the top, center, or bottom of the screen. Supports Background Friendly mode on mobile screens.
Tall Box
Encloses the site's elements in a solid, styleable box that spans the height of the page. Can be positioned on the left, center, or right of the screen. Supports Background Friendly mode on mobile screens, and if positioned on either the left or right of the screen can be set to overlap (or not overlap) the background.

Set the element's Position.

(Box, Wide Box, Tall Box Only) Customize the element's Background, Border and other appearance settings.

(Optional) Click Done to close the panel.

You're done!
