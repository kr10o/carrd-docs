SITES
Setting a Language

If a site's content is written in a language other than Carrd's default (English), follow these steps to change its language:

Click Publish

Click the Settings tab.

Set Language to the language of the site's content.

Click Publish Changes

You're done! Search engines and translation tools (like Google Translate) will now correctly identify the site's language, elements with non-editable labels (like Timers) will now be shown in your selected language*, and if you've selected a language with right-to-left (RTL) script, elements containing text will now be correctly oriented.

If we appear to be missing translations for the selected language (or if a translation is incomplete or isn't accurate), please get in touch.
