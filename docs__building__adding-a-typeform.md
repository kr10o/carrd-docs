Adding a Typeform

The Typeform widget allows you to either embed a typeform or simply add a button to launch one. Here's how to use it:

If you haven't done so already, create a Typeform account and create a typeform.

Back at Carrd, Click Add Element

Click Widget to create a new Widget element.

Set Type to Typeform.

Set URL to the full URL of your typeform.

(Optional) Choose a Style:

Popup (Classic)
Displays a button that opens the typeform as a full-screen popup.
Popup (Drawer)
Displays a button that opens the typeform as a slide-in popup.
Embed
Embeds the typeform in a frame.

(Optional) If using a popup style, change the Button Label.

You're done!
