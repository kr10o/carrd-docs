Adding a Facebook Like Button

The Facebook widget allows you to add a Facebook "Like" button to a site. Here's how to use it:

Click Add Element

Click Widget to create a new Widget element.

Set Type to Facebook Like.

(Optional) Enter the exact URL you'd like to associate with this button, or simply leave it blank to use the site's current URL.

(Optional) Change the Layout, Action, and other Options.

You're done!
