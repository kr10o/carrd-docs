Adding Audio

The Audio element allows you to embed audio tracks and players from SoundCloud, Bandcamp, and more. Here's how:

Click Add Element

Click Audio to create a new Audio element.

Paste in the URL of the audio track, set, or album you'd like to embed. Currently supports URLs in the following formats:

Audiomack
https://audiomack.com/xxxx/song/yyyy
https://audiomack.com/xxxx/album/yyyy
Bandcamp
https://xxxx.bandcamp.com/track/yyyy
https://xxxx.bandcamp.com/album/yyyy
Google Drive
https://drive.google.com/file/d/xxxx/view

Requires audio file to be accessible to "Anyone with the link" (learn more).

Mixcloud
https://www.mixcloud.com/xxxx/yyyy/
SoundCloud
https://soundcloud.com/xxxx/yyyy
https://soundcloud.com/xxxx/sets/yyyy

You're done!
