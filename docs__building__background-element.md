Background Element

The Background element is simply the background that sits behind all of a site's elements (including its Page element). It can be styled to show either a solid color, a gradient, an image, or a video.

Setting a Background Color

Set the background to a solid color

Setting a Background Gradient

Set the background to a two-color gradient

Setting a Background Image

Set the background to an uploaded image

Setting a Background Video

Set the background to a looping video clip

Setting a Background Slideshow

Set the background to a looping image slideshow
