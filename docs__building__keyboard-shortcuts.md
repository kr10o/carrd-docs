Keyboard Shortcuts

The builder supports the following keyboard shortcuts for faster access to certain tasks:

Editing
Ctrl
+
C
Copy the element under the cursor to the clipboard.
Ctrl
+
X
Cut the element under the cursor to the clipboard.
Ctrl
+
V

Paste the previously copied or cut element after the element under the cursor. Note the clipboard element can originate from the current browser tab as well as any other builder tabs you may have open, enabling you to copy, cut, and paste elements between sites.

Clipboard interaction between browser tabs is currently in beta and doesn't support container elements (yet).
Ctrl
+
D
Clone the element under the cursor.
Del
Delete the element under the cursor.
Ctrl
+
Z
Undo the previous action.
Ctrl
+
Shift
+
Z
Redo the next action.
Ctrl
+
S
Quick Publish (or Save) the current site.
Ctrl
+
Shift
+
S
Publish (or Save) the current site.
User Interface
Alt
+
V
View the current published site (or template demo) in a new tab.
Alt
+
P
Preview all animations.
Alt
+
1
Switch to Desktop View.
Alt
+
2
Switch to Mobile View (cropped).
Alt
+
3
Switch to Mobile View (expanded).
Alt
+
E
Show the Elements panel.
Alt
+
S
Show the Sections panel.
Alt
+
←
Move interface to the left side of screen.
Alt
+
→
Move interface to the right side of screen.
