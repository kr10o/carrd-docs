Adding a Site Icon

Requires Pro Lite or higher

Sites can be optionally assigned an icon (or "favicon") by following these steps:

Click Publish

Click the Media tab.

Scroll down to Icon and click Upload

Select an image to use as the site's icon.

Resize and crop as needed, then click Accept

Click Publish Changes

You're done! The selected icon will now show up in the browser address bar as well as anywhere else site icons are used (such as tabs and bookmarks).
