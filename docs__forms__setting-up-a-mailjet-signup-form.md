Setting up a Mailjet Signup Form

Requires Pro Standard or higher

Click Add Element

Click Form to create a new Form element.

Set Type to Signup, then Via Mailjet.

Enter your Mailjet API Key and Secret Key, which can be generated by following these instructions. Note that these can be your primary keys or subaccount keys.

(Optional) Enter a Contact List ID to automatically add contacts to the contact list associated with this ID. Located on your contact lists page under "ID" (for example, 12345678).

(Optional) Check Exclude from Campaigns to automatically add new contacts to your exclusion list for campaigns.

(Optional) Click the Fields tab and rename or toggle the form's fields. Note that some fields may require you to add additional contact properties.

(Optional) Click the Button tab and change the form's submit button Label.

(Optional) Check Collect UTM parameters to automatically include all detected UTM parameters as string contact properties. The following contact properties will be populated if detected: utm_source, utm_medium, utm_campaign, utm_term, and utm_content.

(Optional) Add string contact properties for site_url, site_title and site_form to automatically record the site URL, title and unique form ID with each signup.

You're done! The site should now have a fully functional Mailjet signup form.
