Adding a Footer

When using Sections, you can use a Footer Marker to create a footer, a special region at the bottom of the site that remains visible on every section. Here's how:

Click Add Element

Click Control to create a new Control element.

Set Type to Footer Marker.

Drag the footer marker to where you'd like the footer to begin, then release click to drop it. This assigns all elements after the footer marker (down to the bottom of the site) to the site's footer.

Note: The footer must be physically located after all other elements on the site.

You're done! The elements assigned to the footer should now be visible at the bottom of every section. Note that you can also add a header using a similar process.
