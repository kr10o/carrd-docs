Using Sections

Sections allow you to divide a site into named regions ("sections") that can be linked to and switched between to simulate the effect of having multiple pages on a one-page site:

Sections are also versatile enough for more creative uses beyond just simulating pages; for example, creating full-screen site menus, adding modal-style confirmations to forms, and even building presentations with working navigation buttons.
