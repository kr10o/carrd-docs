SITES
Changing a Title or Description

A site's title and description are usually set the first time it's published. However, they can also be changed at any time by following these steps:

On your Dashboard, click the site's preview image to open the builder.

Click Publish

Change Title and/or Description as needed.

Click Publish Changes

You're done! The site's title and description should now be updated.
