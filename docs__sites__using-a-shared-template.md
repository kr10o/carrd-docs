Using a Shared Template

To use a template that's been shared with you:

Via the My Sites tab

On your Dashboard, click the My Sites tab.

Click the New Site button.

Click the My Templates tab.

Click the Shared tab.

Locate the shared template you want to use and click Select

You're done! The builder should now open with the selected shared template.

Via the Shared Sites tab

On your Dashboard, click the Shared Sites tab.

If you access your shared sites via a folder, click the My Sites tab, click the folders dropdown at the top of the page, then select the Shared folder.

Locate the shared template you want to use and click its Use icon.

You're done! The builder should now open with the selected shared template.
