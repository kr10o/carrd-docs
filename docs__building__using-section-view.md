Using Section View

If you're working on a site that makes use of sections, you can use the builder's Section View to quickly navigate all of the sections within that particular site. Here's how to activate it:

From the Menu

Click Show sections in the menu to bring up the sections panel. Note that if this item doesn't appear in the menu, the site either doesn't use sections or its control elements aren't set up correctly.

Click on the section you'd like to show in section view.

You're done! The selected section should now be the only one visible. To leave section view, click Leave Section View in the menu.

From the Properties Panel

Click the control element of the section you'd like to show in section view.

Click Show in Section View. Note that if this button is disabled, the site's control elements are likely not set up correctly.

You're done! The selected section should now be the only one visible. To leave section view, click Leave Section View in the menu.
