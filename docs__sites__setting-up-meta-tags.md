Adding Meta Tags

Requires Pro Standard or higher

If you need to add custom meta tags to a site (for example, to verify site ownership with Google) follow these steps:

Click Publish

Click the Settings tab.

Under Meta Tags, enter each meta tag in name=content format, where name is the name of the meta tag and content is its content. For example:

google-site-verification=xxxxxxxxxx
robots=noindex
keywords=pirates, robots, ninjas

Click Publish Changes

You're done! The custom meta tags should now be visible in the site's <head> element (immediately after its default meta tags).

Default meta tags take precedence over custom meta tags of the same name and can't be overridden. However, the following are exceptions to this rule and can be overridden if required: og:description, og:site_name, og:title, og:type, and viewport.
