Setting up a SendFox Signup Form

Requires Pro Standard or higher

Click Add Element

Click Form to create a new Form element.

Set Type to Signup, then Via SendFox.

Enter your SendFox personal access token, which can be created by following these instructions.

Enter your SendFox List ID, which is the unique numeric ID of your list (located within the URL of your list page at SendFox, eg. 123456).

(Optional) Click the Fields tab and rename or toggle the form's fields.

(Optional) Click the Button tab and change the form's submit button Label.

You're done! The site should now have a fully functional SendFox signup form.
