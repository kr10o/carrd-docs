Adding a Gumroad Buy Button

The Gumroad widget allows you to add a "Buy" button for a single Gumroad product. Here's how to use it:

If you haven't done so already, create a Gumroad account and add a product.

Back at Carrd, Click Add Element

Click Widget to create a new Widget element.

Set Type to Gumroad.

Enter the Product URL of the Gumroad product you'd like to associate with this button (for example, https://gum.co/XXXXX), which can be found using these instructions.

(Optional) Change the Button Label and other Options.

You're done!
