Setting a Timezone

If a site uses elements that rely on dates or times (such as the Timer element, or the "Require Consent" field of signup and contact forms), setting an explicit timezone is strongly recommended. Here's how to do it:

Click Publish

Click the Settings tab.

Set Timezone to the desired timezone for the site.

Click Publish Changes

You're done! Elements that rely on dates or times will now reflect both using the selected timezone.
