Sharing Access to a Site

Requires Pro Lite or higher

To share access to a site with another user, follow these steps:

Open the Dashboard.

Click the Sites tab.

Locate the site you want to share, then click its Manage icon.

In the sidebar, click Sharing.

Click Add User

Choose the level of Access you want to share with the user:

Admin	Edit	Edit the site with access to the same plan features as its owner, as well as edit the site's Site, Media, and Settings tabs.
Use	Use the site as a starting point for new sites if the site is a custom template and the user has access to any plan features it may use.
Share	Share Editor or Template access to the site with other users, as well as manage users with those levels of access. Note that Admin access can only be shared or managed by the site's owner.
Download	Download the site's unminified HTML, CSS, and JS source code. Requires site owner to be on Pro Plus or higher.
Site Files	Customize various supporting site files belonging to the site. Requires site owner to be on Pro Plus or higher.
Editor	Edit	Edit the site with access to the same plan features as its owner, as well as edit the site's Site, Media, and Settings tabs.
Use	Use the site as a starting point for new sites if the site is a custom template and the user has access to any plan features it may use.
Template	Use	Use the site as a starting point for new sites if the site is a custom template and the user has access to any plan features it may use.

Note that Admin and Editor access can be shared with anyone – even those on the free "Basic" plan. Only the owner of the site is required to be on a Pro plan to use the Sharing feature. Template access can also be shared with anyone provided they have access to the plan features used by the template (if any).

In the Email field, enter the email of the user or person with whom you want to share the site.

Click Add User

You're done! If the provided email was associated with an active Carrd account, that user should now have access to the site via their Shared Sites tab or folder. If you're sharing a custom template, the user will also be able to select it as a starting point for new sites.

If the email isn't associated with an active Carrd account, an invite to create one will be sent to that email. Once the owner of that email clicks through the invite and creates an account, they'll be automatically granted the previously selected level of access to the site.
