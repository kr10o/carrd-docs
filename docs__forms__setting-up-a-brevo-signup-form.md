Setting up a Brevo Signup Form

Requires Pro Standard or higher

Click Add Element

Click Form to create a new Form element.

Set Type to Signup, then Via Brevo.

Enter your Brevo API Key (v3), which can be found by following these instructions.

Enter your Brevo List ID, which is the unique numeric ID of your list (eg. 3).

(Optional) Check Require double opt-in to send visitors an opt-in confirmation email. If you choose to enable this option, be sure to provide the numeric ID of your double opt-in email template (eg. 2).

(Optional) Click the Fields tab and rename or toggle the form's fields. Note that some fields may require you to add additional text attributes to your Brevo contacts.

(Optional) Click the Button tab and change the form's submit button Label.

(Optional) Check Collect UTM parameters to automatically include all detected UTM parameters as text attributes. The following attributes will be populated if detected: UTM_SOURCE, UTM_MEDIUM, UTM_CAMPAIGN, UTM_TERM, and UTM_CONTENT.

(Optional) Add text attributes for SITE_URL, SITE_TITLE and SITE_FORM to your Brevo contacts to automatically record the site URL, title and unique form ID with each signup.

You're done! The site should now have a fully functional Brevo signup form.
