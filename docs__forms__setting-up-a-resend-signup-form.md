Setting up a Resend Signup Form

Requires Pro Standard or higher

Click Add Element

Click Form to create a new Form element.

Set Type to Signup, then Via Resend.

Enter your Resend API Key, which can be created by following these instructions. Be sure to create a key with Full access permissions.

(Optional) Check Unsubscribe to automatically unsubscribe new contacts from broadcasts.

(Optional) Add one or more segments to which new contacts should be added.

(Optional) Add one or more topics to apply to new contacts.

(Optional) Click the Fields tab and rename or toggle the form's fields. Note that some fields may require you to add additional contact properties to your Resend audience.

(Optional) Click the Button tab and change the form's submit button Label.

(Optional) Check Collect UTM parameters to automatically include all detected UTM parameters as string contact properties. The following contact properties will be populated if detected: utm_source, utm_medium, utm_campaign, utm_term, and utm_content.

(Optional) Add string contact properties for site_url, site_title and site_form to your Resend audience to automatically record the site URL, title and unique form ID with each signup.

You're done! The site should now have a fully functional Resend signup form.
