Setting up an ActiveCampaign Signup Form

Requires Pro Standard or higher

Click Add Element

Click Form to create a new Form element.

Set Type to Signup, then Via ActiveCampaign.

Enter your ActiveCampaign API URL, which can be found by following these instructions.

Enter your ActiveCampaign API Key, which can be found by following these instructions.

Choose the Action you'd like to happen when a user submits this form:

Create Contact
Simply create a new contact.
Add Contact to List
Create a new contact, then add it to a list. If you choose this action, you'll need to provide the numeric List ID associated with your list (located within the URL of your list's page after "listid=", eg. 1).
Add Contact to Automation
Create a new contact, then add it to an automation. If you choose this action, you'll need to provide the numeric Automation ID associated with your automation (located within the URL of your automation's page after "series/", eg. 1). This action is recommended if you'd like to create a double opt-in process for your subscribers.

(Optional) Click the Fields tab and rename or toggle the form's fields.

(Optional) Click the Button tab and change the form's submit button Label.

(Optional) Check Collect UTM parameters to automatically include all detected UTM parameters as custom text input fields. The following fields will be populated if detected: UTM_SOURCE, UTM_MEDIUM, UTM_CAMPAIGN, UTM_TERM, and UTM_CONTENT.

(Optional) Add custom text input fields for SITE_URL, SITE_TITLE and SITE_FORM to your ActiveCampaign contacts to automatically record the site URL, title and unique form ID with each signup.

You're done! The site should now have a fully functional ActiveCampaign signup form.
